Curriculum — textbook-first

Effort weighted to coding (your gap) while keeping the stats edge sharp. Video only where it beats a book by a huge margin. Most resources are free/open-access.

Coding the #1 gap · continuous → peak summer 2028

The runway is ~2 years, not "during the master." Internship recruiting opens ~Aug 2028, at master-start — so you must be OA-ready by then. Build continuously through undergrad, then intensify in summer 2028 (the free post-grad window). Key distinction: the EPFL route needs coding SKILL to pass the OA, NOT a top rating — the "Codeforces overrides your GPA/non-target" effect is for the direct-from-Almaty route the master removes. So aim OA-readiness; a high rating is quant upside, not the requirement.
  • Codeforces — your coding-to-par vehicle (individual, rating-based — solves the ICPC-teammate problem). Verify your account (gov/uni ID) so the rating is credible; the firm's proctored OA is the trust backstop. Aim as high as you get, Expert→CM — dual-use: your interview coding + the quant OA + the verified non-target override (Jane Street fast-tracks CF Grandmasters). Realistic: CM (1900) is ~2 yrs of hard practice — upside, not a must-hit.
  • Grokking Algorithms 2e (Bhargava, 2024) — the on-ramp before contests, Fall 2026
  • NeetCode 150 (video exception — pattern engine) + LeetCode-medium fluency — the base under Codeforces, continuous
  • Python for Data Analysis 3e (McKinney, free) + Effective Python 3e — numpy/pandas fluency + idioms, both years
  • SQL for Data Scientists (Teate) + Mode/DataLemur — one concentrated block, Spring 2027
  • Pro Git + pytest 2e — applied directly to the A1 repo (git + tests from day one)
  • Summer 2028 = the coding peak — intensify to OA-ready in the free post-grad window, before fall-2028 recruiting
  • Defer to reference: Skiena, Pragmatic Programmer, APOSD. EPI = the harder problem bank — quant-only, and only later.

Math lean · time-boxed behind coding

  • Coursework LA only until MT1173 (15 Oct 2026) — no added math load in that window
  • Abbott, Understanding Analysis 2e — the rigor signal (selective; you have MT2116/2176), late 2026 → mid-2027
  • Deferred (the master supplies these; not admission gates): Boyd Convex Optimization + EE364a; Deisenroth MML + Strang 18.065. Axler stays on the later foundations ladder (rigorous LA) — not in this window.

ML re-derive rigorously — from-scratch builds double as coding reps

  • ISLP (free) + reimplement each method in pure numpy (one tested repo) — Fall 2026, in full
  • Prince, Understanding Deep Learning (free) + Karpathy Zero-to-Hero (the one video exception — builds micrograd→GPT by hand) — Spring 2027, in full
  • Dip-in references only: Bishop DL: Foundations, ESL, Raschka, Huyen DMLS (read near job interviews, not admission)
  • If buying an applied reference: Géron's new PyTorch edition (Dec 2025) supersedes the 2022 TF/Keras book.

Stats your differentiator — 80% maintain + 2 targeted adds

  • Add — causal inference: Hernán–Robins What If + Cunningham Mixtape — by mid-2027, folded into the summer RA
  • Add — applied regression: Gelman Regression and Other Stories (R/Stan = coding reps) — Year 3, light parallel
  • Conditional: Tsay Analysis of Financial Time Series — Year 4, only if quant goes primary
  • Skip as a study project: Wasserman All of Statistics (redundant with C-B; shelf reference)
